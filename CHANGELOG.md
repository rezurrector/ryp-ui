# @ryp/ui

## 0.1.0

### Major Changes

- Initial release of ryp-ui with comprehensive setup:
  - shadcn/ui components with Tailwind CSS
  - tsup for fast, tree-shakable builds
  - pnpm for efficient dependency management
  - Vitest for fast, modern testing
  - Storybook 8 for interactive documentation
  - MSW for API mocking
  - Changesets for semantic versioning
  - Husky + lint-staged for Git hooks
  - VP CLI for enhanced Vite configurations
  - TypeScript strict mode
  - Conventional Commits support

### Features

- Button component with multiple variants and sizes
- Utility functions (cn, sleep, debounce, capitalize)
- Global styles with Tailwind CSS
- MSW handlers for API mocking
- GitHub Actions workflows for CI, release, and Storybook
- Comprehensive README with usage instructions
